AI Addon Finder

Агент понимает запрос, ищет на GitHub и смешивает с каталогом. Ключи не обязательны — статическая страница на GitHub Pages.

Ключи только в localStorage этого браузера. Репозиторий и Pages ключей не содержат. Cursor-модели отсюда вызвать нельзя.

Enter — поиск, Shift+Enter — новая строка

    Пусто · Empty

    Нажмите пример или введите задачу. Без ключа агент ходит в публичный GitHub Search и запасной каталог. С ключом OpenRouter — лучше план и формулировки «для чего».

    Не удалось загрузить каталог. Браузеры блокируют file://. Откройте через локальный сервер: python3 -m http.server 8080 и зайдите на http://localhost:8080.
